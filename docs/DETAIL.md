# MiniMax Code 接入

把 **MiniMax Code** 的免费额度接入 DeepSeek Harness：无需手工管理 API Key，登录一次即可在模型选择器中使用 MiniMax 模型。

## 功能

- **一键登录**：通过 MiniMax Code 授权流程完成登录，凭据保存在宿主凭据库中，不会出现在任何配置文件里。
- **模型接入**：登录后自动把 MiniMax 模型注册到模型选择器，走 MiniMax Code 专属通道消耗订阅/免费额度，而非按量计费余额。
- **额度显示**：输入框旁实时显示剩余额度与签到状态。
- **每日签到**：自动完成 MiniMax Code 每日签到领取积分；错过的时间点会按配置的重试间隔自动补签。

## 使用

1. 安装插件后，在设置中找到 MiniMax Code 接入，点击「登录」完成授权。
2. 在对话输入框的模型选择器中选择 MiniMax 模型。
3. 每日签到默认开启，可在插件配置中关闭（`checkIn.enabled`）或调整失败重试间隔（`checkIn.autoRetryMinutes`）。

## 限制

- 额度规则以 MiniMax 官方为准：免费额度数额与有效期可能随时调整。
- 插件仅转发官方接口；若官方接口变更导致功能失效，请更新插件。
